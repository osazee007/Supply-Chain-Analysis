# Supply Chain Analysis

## Project Overview
Analysed a real supply chain dataset of 100 products across multiple suppliers and locations using SQL, Excel and Power BI.

## Tools Used
- SQL (SQLite) — data extraction and analysis
- Microsoft Excel — data storage and summaries
- Power BI Desktop — interactive dashboard

## Key Findings
- Skincare is the highest revenue product type generating over $241,000
- Supplier 1 is the top performing supplier at $157,529
- Mumbai generates the most revenue by location
- Air transport is the most expensive shipping mode at $6.02 average
- Carrier B has the highest total shipping cost at $236.90
- Haircare has the highest defect rate at 2.4%
- Cosmetics have the highest average price at $57.36
